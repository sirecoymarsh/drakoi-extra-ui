# DraKoi Extra UI

《드라†코이》 한국어 패치의 엑스트라 UI 디자인 작업용 **비공개** 저장소입니다. 실제 게임 엔진과 음원은 포함하지 않습니다.

## 추가·변경 사항

이 저장소는 **번역 패치 자체가 아니라**, 《드라†코이》 한국어 패치에 원판에 없던 **「엑스트라」 메뉴와 그 안의 화면들(UI)을 새로 더하는 작업**의 소스와 검수 자료입니다. 이 절은 커밋 기록과 소스 코드(`source/`, `native_update_review.c`), `docs/upload-manifest.json`에서 확인한 내용을 정리한 것입니다. 괄호 안은 근거(커밋 앞 7자, 파일 이름)이며, 확실하지 않은 내용은 「(추정)」으로 표시했습니다.

### 무엇을 더했나 (원판 대비)

게임 안에서 엑스트라 화면에 들어가면, 이 DLL(`ko.dll`)이 게임 창 위에 자체 창을 띄워 아래 여섯 메뉴를 보여 줍니다(`source/extra07_player.inc`). 게임 화면 구석의 표식 픽셀로 엑스트라 진입을 알아채고, 「타이틀로」·「엑스트라로」는 원래 게임 스크립트의 버튼을 대신 눌러 넘깁니다.

| 메뉴 | 내용 |
| --- | --- |
| 드라마 CD · 은빛 악마와 금빛 도깨비 | 드라마 CD 13트랙을 이어서 재생. 자막 629줄(한국어 / 일본어 / 동시 표시), 문장을 눌러 그 문장만 다시 듣기, 트랙별 재생 위치 기억, 쪽 넘기기, 이전·다음 트랙, 처음부터, 음량 조절(5단위), 진행 막대 클릭으로 이동, 트랙 제목 번역 켜기/끄기, 메뉴 그림(책자 표지·주인공·교실 표지)과 재생 화면 배경 고르기, 그림 크게 보기 |
| 우로보로스의 사랑 | 하가네야 진의 외전 소설(상편·하편)을 문단 단위로 읽는 화면. 읽던 위치 자동 저장(`side-black/reading.ini`), 「이어서 읽기」, 예전 책갈피 형식 호환(`legacy_bookmarks.h`), 원고를 고친 뒤 F5로 다시 읽기 |
| 사운드 모드 | 게임 음악 17곡(보컬·반주·짧은 버전·배경음) 재생, 반복 꺼짐 / 한 곡 반복 / 전체 반복, 보컬 자막이 켜져 있으면 가사(원문 + 한국어) 표시, CD 책자의 미니 캐릭터 그림 |
| 추가 CG 감상 | 원판 CG 모드에 등록되지 않은 게임 그림 231장(일러스트·배경·스탠딩·컷인)을 썸네일 목록과 확대 보기로 감상(`source/gallery_data.h`) |
| 플로우 차트 | 본편 주요 선택지 네 곳과 엔딩 네 종류의 연결을 한 장의 차트로 표시. 노드를 누르면 해당 장면 그림을 봄 |
| 타이틀로 | 게임 타이틀 화면으로 돌아감 |

그 밖에 본편 플레이 중 **보컬 곡 가사 자막**(라틴어 원문 + 한국어)을 화면 위쪽에 띄우는 기능이 있습니다. 음악 소리의 지문(fingerprint)으로 곡과 위치를 찾아 맞춥니다. DLL 옆 `vocal_mod.ini`의 `[VocalSubtitles] Enabled=1`일 때 켜지고, 게임 중 **F8**로 보이기/숨기기를 바꿉니다(`source/vocal_probe.c`, `source/vocal_cues.h`). 이 기능이 꺼져 있어도 엑스트라와 사운드 모드는 쓸 수 있습니다.

### 번역 범위

- 이 저장소에서 새로 번역한 것은 없습니다. 엑스트라 화면의 메뉴 문구, 드라마 CD 자막, 소설, 가사, 트랙 제목 번역은 기존 Codex internal 작업물을 그대로 옮겨 왔습니다(`README.md` 「코드와 자료」, `docs/upload-manifest.json`).
- 드라마 CD 일본어 자막은 음성을 받아 적은 초안이며, 공식 대본과 대조하지 않았습니다.
- 함께 링크하는 미리 컴파일된 한국어 패치 본체(`build/ko_hook_r2e.obj`, `build/ko_r2c_ui.obj`)에는 원판 시스템 메시지(DirectX·사운드·CG 모드 등 오류·설정 창 문구)의 한국어화가 들어 있습니다. 이 부분은 한국어 패치 본편 쪽 작업입니다(`source/ko_r2c_ui.c`, `source/ko_hook_r2e.c`).

### 단축키·조작

엑스트라 화면은 800×600 기준으로 그린 뒤 창 크기에 맞춰 늘립니다. 마우스 오른쪽 클릭은 대부분 화면에서 「뒤로」입니다.

| 화면 | 키·조작 | 동작 |
| --- | --- | --- |
| 공통(드라마 CD·사운드) | Space | 재생 / 일시정지 |
| 공통 | Esc | 목록·이전 화면으로(엑스트라 허브에서는 타이틀로) |
| 드라마 CD | 문장 클릭 | 그 문장만 다시 듣기(끝나면 원래 위치로 돌아감) |
| 그림 보기(드라마 CD) | 휠 / 드래그 / 0·Home / ← → | 포인터 중심 확대·축소 / 이동 / 화면 맞춤 / 그림 바꾸기 |
| 소설 | 클릭·Space·Enter·→·PageDown / ←·PageUp / Home / End / F5 | 다음 문단 / 이전 문단 / 편 처음 / 편 끝 / 원고 다시 읽기 |
| 추가 CG 감상 | 휠 / 드래그 / ← → PageUp PageDown / 0·Home / B / Esc | 확대·축소 또는 목록 넘기기 / 이동 / 이전·다음 그림 / 맞춤 / 배경색 바꾸기(3종) / 목록으로 |
| 플로우 차트 | 휠 / 드래그 / 0 / Home / ← → PageUp PageDown / ↑ ↓ | 확대·축소 / 이동 / 전체 보기 / 처음 상태 / 노드 이동 / 위아래 이동 |
| 본편 플레이 중 | F8 | 보컬 가사 자막 보이기 / 숨기기 |

Ctrl+휠은 엑스트라 화면이 가로채지 않고 게임에 넘깁니다.

### 화면·글꼴

- 엑스트라 화면의 한국어는 맑은 고딕, 일본어 자막은 Yu Gothic으로 그립니다(`source/extra07_player.inc`).
- 사운드 모드의 미니 캐릭터 그림은 WIC Fant 보간으로 한 번 줄여, 가는 인쇄 윤곽이 뭉개지지 않게 했습니다(`source/sound_player.inc`).
- 한국어 패치 본체의 글꼴 정책 R2e: 백로그 글꼴(맑은 고딕 -17/600)의 높이만 셀 높이 17픽셀로 바꿔 백로그 글자 크기를 바로잡았고, 본문·선택지 글꼴 크기는 그대로 두었습니다(`source/ko_font_policy_r2e.h`, `source/test_backlog_font_policy.c`).
- **현재 요청(진행 중)**: 엑스트라의 단순한 네모 패널을 게임 타이틀 화면과 어울리게 다듬는 작업입니다. `main`에는 아직 반영되지 않았고, 아래 `extra-ui-title-style` 브랜치에서 진행 중입니다.

### 설치·빌드 방식

- Windows + Visual Studio C++ x86 도구로 `build.bat`을 실행하면 `build/ko.dll`이 나옵니다(`/W4 /WX`, CFG·DEP·ASLR 켬). 게임 폴더에 자동으로 설치하지 않으며, 게임에 넣기 전에는 반드시 사용자 확인을 받습니다.
- 처음 올린 시점의 빌드 결과 DLL 해시(`b6e94356…ff5bfe8`)가 당시 설치된 DLL과 같다는 것을 확인했습니다(`docs/upload-manifest.json`).
- 실행에 필요한 그림(`extra07/`, `sound-mode/`, `extra-gallery/`, `side-black/`)은 이 저장소에 있지만, 드라마 CD 음성·음악 파일과 게임 본체·`.pak`·세이브는 포함하지 않습니다. 소리 재생은 게임이 있는 PC에서만 확인할 수 있습니다.
- `review_update.bat`이 실제 GDI 렌더러로 화면을 그려 보는 검수 프로그램을 빌드·실행합니다. 검수 모드: `--menu-introduction(-render)`, `--menu-art-selection`, `--title-toggle-intro`, `--subtitle-modes`, `--sentence-replay`, `--drama-art`, `--backgrounds`, `--novel-intro`, `--sound-art`, `--cover-sound`, `--gallery-labels`, `--flowchart`.

### 알려진 문제

- 타이틀 스타일 디자인은 아직 `main`에 합쳐지지 않았고, 게임 안에서 직접 조작해 본 기록이 없습니다(추정: Windows 빌드·렌더 검수는 브랜치 작업 중 따로 했을 수 있음).
- Linux에서는 이 Windows GDI DLL을 실행하거나 MSVC 검수를 끝낼 수 없습니다. 빌드·렌더 확인은 Windows에서 해야 합니다.
- 오디오(드라마 CD·사운드 모드·보컬 자막) 재생 확인은 음원이 있는 게임 PC에서만 가능합니다.
- `source/ko_hook_r2e.c`를 다시 빌드하려면 원래 한국어 패치 생성 과정의 `ko_map.h` 등이 더 필요합니다. 지금은 미리 컴파일된 오브젝트를 그대로 링크합니다.
- 드라마 CD 일본어 자막은 공식 대본과 대조하지 않은 받아쓰기 초안입니다.

## 현재 요청

엑스트라의 단순한 네모 패널을 게임 타이틀 화면과 어울리는 디자인으로 다듬습니다. 먼저 `docs/ui-reference/title-layout.png`와 현재 화면들을 확인하세요. 기존 재생·자막·메뉴 이동 기능은 유지합니다. **게임 실행 폴더에 파일을 복사하거나 적용하기 전에는 반드시 사용자에게 확인받으세요.**

## 빌드

Windows, Visual Studio C++ x86 도구와 Windows SDK가 필요합니다. `vswhere`로 설치 경로를 찾으며, 준비된 x86 개발자 명령 프롬프트도 사용할 수 있습니다.

```powershell
.\build.bat
```

결과는 `build/ko.dll`입니다. 필요한 임시 폴더는 자동 생성됩니다. 빌드 명령은 게임 실행 폴더에 설치하지 않습니다. Linux 클라우드에서는 코드를 수정할 수 있지만 이 Windows GDI DLL을 그대로 실행하거나 MSVC 검수를 완료했다고 주장할 수 없습니다. Windows 환경에서 빌드/렌더 검증을 수행하세요. GitHub Actions 실행은 이 저장소에 추가하지 않았습니다.

## 화면 검수

음원 없이 드라마 CD 목록의 세 가지 표지 배치를 렌더링합니다.

```powershell
.\review_update.bat --menu-introduction-render
```

결과는 `rendered/drama-introduction-0.bmp`부터 `-2.bmp`입니다. `--menu-introduction`은 현재 배치의 클릭 영역까지 확인하므로 좌표를 바꾸면 해당 기대값도 의미에 맞게 갱신하세요. `--flowchart`, `--subtitle-modes`, `--gallery-labels` 등 다른 검수 모드는 변경한 기능에 필요한 경우에만 실행합니다. 기존 검증 결과를 재사용하고, 전체 검수를 무조건 반복하지 않습니다. 음원을 제외했으므로 오디오 재생 검수는 게임이 있는 PC에서 별도로 해야 합니다.

## 로컬 연결

- 소스: 작업 PC의 로컬 작업 폴더(경로는 이 README에 적지 않습니다).
- 게임 실행본: 작업 PC의 검수용 게임 실행 폴더. 이 폴더에 적용하기 전에는 반드시 사용자 확인을 받습니다(경로는 `AGENTS.md` 참고).
- 저장소의 이미지는 해당 UI 작업을 위한 자료입니다. 공개 저장소로 전환하거나 별도 배포하지 않습니다.
